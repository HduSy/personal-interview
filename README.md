# 2026-Front-end-Interview 🎯

面试刷题记录，有目标就行，一步一步总能达成。系统梳理前端知识体系。

## 📂 目录结构

```
fe-interview/
├── javascript/        # JavaScript 核心
├── css/               # CSS 与布局
├── browser/           # 浏览器原理 & 网络
├── framework/         # 框架（React / Vue）
├── algorithm/         # 算法与数据结构
├── engineering/       # 工程化（构建 / CI/CD / 监控）
├── system-design/     # 系统设计
└── notes/             # 面试复盘 & 杂记
```

## 📝 约定

- 每个目录下用 `.md` 文件记录，文件名即主题（如 `closure.md`、`flexbox.md`）
- 格式：**问题 → 核心要点 → 代码示例 → 延伸思考**
- `notes/` 放面试复盘和零散心得
- 用 Git 管理版本，方便回顾进步轨迹
