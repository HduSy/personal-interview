# 02. CSS 选择器有哪些？优先级？哪些属性可以继承？

## 1. 选择器分类

### (1) 基础与关系选择器

| 类型 | 语法示例 | 匹配规则说明 |
| --- | --- | --- |
| **通配符选择器** | `*` | 匹配页面中的所有 HTML 元素（性能消耗相对较高） |
| **元素 / 标签选择器** | `div`, `p`, `span` | 匹配所有对应的 HTML 标签名 |
| **类选择器** | `.btn`, `.card` | 匹配包含对应 `class` 属性值的元素 |
| **ID 选择器** | `#header`, `#app` | 匹配具有特定唯一 `id` 属性值的元素 |
| **并集 / 分组选择器** | `h1, h2, .title` | **逗号分隔**，将相同的样式规则同时应用于多个不同的选择器目标 |
| **后代选择器** | `nav a` | 匹配 `nav` 内部**任意层级**的所有 `<a>` 元素（空格连接） |
| **子代选择器** | `ul > li` | 仅匹配 `ul` 的**第一代直接子元素** `<li>` |
| **相邻兄弟选择器** | `h2 + p` | 紧跟在 `h2` 后面且与其同级的**第一个** `<p>` 元素 |
| **通用兄弟选择器** | `h2 ~ p` | 位于 `h2` 之后且与其同级的**所有** `<p>` 兄弟元素 |

分组选择器有连带失效问题：逗号列表中任一选择器不被识别，**整条规则失效**。`h1, ::-webkit-scrollbar { color: red }` 在 Firefox 下连 `h1` 也不生效；改用 `:is(h1, ::-webkit-scrollbar)` 可避免。

### (2) 属性选择器

| 语法 | 说明 | 示例场景 |
| --- | --- | --- |
| `[attr]` | 拥有该属性即可 | `input[disabled]` |
| `[attr="val"]` | 属性值完全等于指定值 | `input[type="text"]` |
| `[attr^="val"]` | 属性值以指定字符串**开头** | `a[href^="https://"]` |
| `[attr$="val"]` | 属性值以指定字符串**结尾** | `a[href$=".pdf"]` |
| `[attr*="val"]` | 属性值包含指定**子串** | `img[src*="avatar"]` |
| `[attr~="val"]` | 包含以空格分隔的独立单词 | `[class~="active"]` |

### (3) 伪类与伪元素

伪类匹配已有节点的状态，用单冒号；伪元素生成抽象节点，用双冒号。

- **伪类**：`:hover`、`:active`、`:focus-visible`、`:checked`、`:first-child`、`:nth-child(n)`、`:empty`、`:not()`、`:is()`、`:where()`、`:has()`。
- **伪元素**：`::before` / `::after`（需配合 `content`）、`::first-letter`、`::first-line`、`::placeholder`、`::selection`。

## 2. 优先级计算

| 级别 | 对应的选择器成分 | 单个权重值 |
| :---: | --- | :---: |
| **a** | **内联样式**：`<div style="...">` | `(1, 0, 0, 0)` |
| **b** | **ID 选择器**：`#main`, `#nav` | `(0, 1, 0, 0)` |
| **c** | **类、属性选择器、伪类**：`.box`, `[type="text"]`, `:hover` | `(0, 0, 1, 0)` |
| **d** | **元素选择器、伪元素**：`div`, `p`, `::before` | `(0, 0, 0, 1)` |
| **无** | **通配符（`*`）、组合符（`+`, `>`, `~`）** | `(0, 0, 0, 0)` |

1. **从左到右逐位比较，高位大者胜出**。权重不是十进制累加：11 个类 `(0, 0, 11, 0)` 也赢不了 1 个 ID `(0, 1, 0, 0)`。
2. **权重相同时按源码顺序**，后定义的覆盖先定义的；与 `class` 属性中的书写顺序无关。
3. **`!important` 高于普通声明**；两个同类声明都带 `!important` 时，再比较选择器权重。
4. **`:is()` / `:not()` / `:has()` 取括号内最高权重**；**`:where()` 恒为 `(0, 0, 0, 0)`**，适合写易被覆盖的公共样式。

## 3. 属性继承

| 类别 | 常见典型属性 | 为什么这么设计？ |
| --- | --- | --- |
| **可继承**<br/>（文本与排版） | • **字体**：`font-family`, `font-size`, `font-weight`, `line-height`<br/>• **文本**：`color`, `text-align`, `text-indent`, `letter-spacing`<br/>• **其他**：`visibility`, `cursor`, `list-style`, `quotes` | 让文章层级共享同一套字体与排版，避免逐层重复声明 |
| **不可继承**<br/>（盒模型与布局） | • **盒模型**：`width`, `height`, `margin`, `padding`, `border`<br/>• **布局**：`display`, `flex`, `grid`, `float`, `clear`<br/>• **定位**：`position`, `top/bottom/left/right`, `z-index`<br/>• **视觉**：`background`, `overflow`, `transform`, `filter` | 盒模型若被继承，父元素加边框会让所有后代都套上边框 |

- **继承来的值权重为 0**，低于通配符：`body { color: blue }` 配合 `* { color: black }` 时，`<p>` 最终是黑色。
- **`opacity` 不可继承**，但父元素设了半透明后整体合成，子元素写 `opacity: 1` 也无法恢复。
- **四个控制关键字**：`inherit` 强制继承、`initial` 恢复初始值、`unset`（可继承则 inherit，否则 initial）、`revert` 回退到浏览器默认样式。
