# 03. CSS 中的像素单位有哪些？

## 1. CSS 长度单位分绝对和相对两类，px 是唯一常用的绝对单位

CSS 长度单位分绝对和相对两类。绝对单位尺寸固定，相对单位相对某个基准计算。除 `px` 外，其余绝对单位基本只用于打印样式，并且都以 `px` 为基准换算。

| 单位 | 全称 | 与 px 的换算 | 说明 |
| --- | --- | --- | --- |
| **`px`** | pixel | 1 | **CSS 逻辑像素**，不是物理像素 |
| `cm` | centimeter | 1cm ≈ 37.8px | 厘米 |
| `mm` | millimeter | 1mm ≈ 3.78px | 毫米 |
| `Q` | quarter-millimeter | 1Q ≈ 0.945px | 四分之一毫米 |
| `in` | inch | 1in = 96px = 2.54cm | 英寸 |
| `pt` | point | 1pt = 1.333px | 磅，1/72 英寸 |
| `pc` | pica | 1pc = 16px | 派卡，12 磅 |

`px` 是 CSS 逻辑像素，不是物理像素。1 CSS px 在高 DPR 屏幕上会对应多个物理像素；浏览器缩放会改变这个映射，但用户设置的浏览器默认字号不会影响 `px`。想要 1 物理像素细线，需要按 `devicePixelRatio` 反算，或用 `0.5px` 配合媒体查询兜底。

## 2. 字体相对单位：em 随嵌套放大，rem 只认根字号

字体相对单位参照当前字体或根字体计算。`em` 在 `font-size` 属性自身上使用时参照父元素的 `font-size`，因此嵌套会逐级放大；`rem` 永远参照根元素 `<html>` 的 `font-size`，不会放大。

| 单位 | 参照物 | 典型用途 |
| --- | --- | --- |
| **`em`** | 元素的 `font-size`（在 `font-size` 属性自身上使用时，参照父元素的 `font-size`） | 组件内相对缩放、按钮内边距随字号变化 |
| **`rem`** | 根元素 `<html>` 的 `font-size`（默认 16px） | 全局尺寸体系、响应式字号 |
| `ex` | 当前字体中小写字母 `x` 的高度 | 极少使用，字体度量相关 |
| `ch` | 当前字体中数字 `0` 的宽度 | 等宽数字、输入框按字符数定宽 |
| `lh` / `rlh` | 元素 / 根元素的行高 | 让间距与行高对齐 |
| `cap` / `ic` | 大写字母高度 / 表意字符宽度 | 多语言排版场景 |

```css
.parent    { font-size: 20px; }
.child     { font-size: 1.2em; }        /* 参照父元素 → 24px */
.grandchild{ font-size: 1.2em; }        /* 参照 .child → 28.8px，逐级放大 */
```

```css
.child     { font-size: 1.2rem; }       /* 1.2 × 16 = 19.2px */
.grandchild{ font-size: 1.2rem; }       /* 同样是 19.2px */
```

## 3. 视口与容器单位：全屏用 dvh，组件级响应式用 cq 单位

视口单位相对视口尺寸计算。移动端 `100vh` 会因地址栏收起展开而变化，导致元素被遮挡；全屏布局优先用 `dvh`，要求高度不跳动时用 `svh`。

| 单位 | 含义 |
| --- | --- |
| `vw` | 视口宽度的 1% |
| `vh` | 视口高度的 1% |
| `vmin` | `vw` 与 `vh` 中较小者的 1% |
| `vmax` | `vw` 与 `vh` 中较大者的 1% |

| 单位 | 含义 |
| --- | --- |
| `svh` / `svw` | 地址栏展开、视口最小时的尺寸 |
| `lvh` / `lvw` | 地址栏收起、视口最大时的尺寸 |
| `dvh` / `dvw` | 随地址栏状态动态变化 |

容器相对单位要求祖先元素声明 `container-type`，尺寸相对查询容器而非视口计算，适合组件级响应式。

| 单位 | 含义 |
| --- | --- |
| `cqw` / `cqh` | 查询容器宽度 / 高度的 1% |
| `cqi` / `cqb` | 容器行向 / 块向尺寸的 1% |
| `cqmin` / `cqmax` | 上面两组中较小 / 较大者的 1% |

## 4. 百分比参照物不统一，垂直 padding 参照宽度

百分比不是长度单位，难点在参照物因属性而异。`padding` 和 `margin` 的上下方向也参照包含块宽度，`padding-top: 50%` 因此常被用于固定宽高比。

| 属性 | 参照物 |
| --- | --- |
| `width` / `height` | 包含块的内容区宽度 / 高度 |
| **`padding` / `margin`（含上下方向）** | **包含块的宽度**（垂直方向也参照宽度） |
| `font-size` | 父元素的 `font-size` |
| `line-height` | **自身**的 `font-size` |
| `transform: translate()` | **自身**的尺寸 |
| `top` / `left` | 包含块的高度 / 宽度 |

## 5. line-height 无单位继承倍数，带单位继承像素值

`line-height` 写成数字、百分比、em 或 px 时，在写法所在元素上算出的行高相同，区别只在继承：无单位数字继承的是倍数，子元素按自身字号重算；带单位或百分比继承的是算好的像素值，子元素字号变大时会挤压。

```css
.a { line-height: 1.5; }    /* 无单位：继承倍数，子元素按自身字号重算 */
.b { line-height: 1.5em; }  /* 有单位：先算成 px 再继承，子元素字号变大行高不变 */
```

| 写法 | 元素自身算出的行高 | 子元素继承到的是什么 | 子元素字号变大后 |
| --- | --- | --- | --- |
| `line-height: 1.5`（数字） | 24px | **数字 `1.5` 本身** | 按子元素自己的字号重新计算，等比放大 |
| `line-height: 150%` | 24px | 算好的 **24px** | 不跟随，挤压 |
| `line-height: 1.5em` | 24px | 算好的 **24px** | 不跟随，挤压 |
| `line-height: 24px` | 24px | 固定的 **24px** | 不跟随，挤压 |
| `line-height: normal` | 由字体度量决定（约 1.2） | 关键字 `normal` | 跟随，但倍数由字体决定，不可控 |

`normal` 的值由字体自身的度量信息决定，跨字体、跨平台不一致；需要可控就显式写数字。

```css
/* 带单位：子元素继承算好的 24px */
.card {
  font-size: 16px;
  line-height: 1.5em;
}
.card .title {
  font-size: 32px;      /* 继承到的行高仍是 24px，文字会挤压 */
}

/* 无单位：子元素按自身字号重算 */
.card {
  font-size: 16px;
  line-height: 1.5;
}
.card .title {
  font-size: 32px;      /* 行高变成 1.5 × 32 = 48px */
}
```

全局推荐写无单位值，让所有后代按自身字号保持比例：

```css
body { line-height: 1.5; }
```

少数场景需要固定行高，例如固定高度控件的垂直居中（`height: 40px; line-height: 40px`）、需要严格对齐的表格或列表、图标与文字的基线对齐。

## 6. 选型建议

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 字号 | `rem` | 跟随用户设置的根字号，无障碍友好；`px` 会被浏览器默认字号设置忽略 |
| 间距 / 圆角 / 边框 | `rem` 或 `px` | 设计稿按 px 标注时可直接用 `px`；`rem` 更利于整体缩放 |
| 组件内部相对尺寸 | `em` | 按钮内边距、图标尺寸随字号自动适配 |
| 流体排版 | `clamp(最小, 中间值 + vw, 最大)` | 例如 `font-size: clamp(1rem, 0.5rem + 1vw, 1.5rem)` |
| 全屏高度 | `dvh` / `svh` | 规避移动端地址栏导致的 `vh` 抖动 |
| 组件级响应式 | `cqw` / `cqi` + `container-type` | 优于媒体查询的组件复用能力 |
| 打印样式 | `pt` / `cm` / `mm` | 纸面尺寸的语义单位 |
