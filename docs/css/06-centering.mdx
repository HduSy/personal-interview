# 06. 元素水平垂直居中的方法有哪些？如果元素不定宽高呢？

## 高频问答

### 1. 面试官：元素水平垂直居中的方法有哪些？如果元素不定宽高呢？

**回答**：居中方案按「谁分配父容器的剩余空间」分两类：

- **需要确定尺寸**：负 margin、`inset: 0` + `margin: auto`、`line-height`、`calc` 计算偏移。
- **不依赖尺寸**：`transform` 百分比位移、Flexbox、Grid、`table-cell`、块级 `align-content`。

**元素不定宽高，只能用第二类**——第一类的偏移量全部按自身尺寸的一半计算，尺寸不知道就算不出来。

### 2. 面试官：需要确定尺寸的方案具体怎么做？

**回答**：四种，共同点是偏移量按自身尺寸的一半计算，尺寸一变就要同步改。

**绝对定位 + 负 margin**：`top/left: 50%` 把元素左上角移到父容器中心，负 margin 按自身尺寸的一半拉回。

```css
.parent { position: relative; }

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 200px;
  height: 100px;
  margin-top: -50px;    /* 高度的一半 */
  margin-left: -100px;  /* 宽度的一半 */
}
```

**绝对定位 + `inset: 0` + `margin: auto`**：四边偏移归零后，剩余空间由 `margin: auto` 平分。要求父元素有定位上下文、子元素确定宽高（`<img>` 等替换元素除外）；只写 `inset: 0` 元素会靠左。

```css
.parent { position: relative; }

.child {
  position: absolute;
  inset: 0;             /* top/right/bottom/left 全为 0 */
  width: 200px;
  height: 100px;
  margin: auto;
}
```

**`line-height` 单行文本**：行高撑高行盒实现垂直居中。只适合单行，多行会溢出；行高会被子元素继承，需要在子元素上重置。

```css
.parent {
  height: 100px;
  line-height: 100px;   /* 与高度相等 */
  text-align: center;
}
```

**`calc` 计算偏移**：与负 margin 等价，同样必须知道尺寸。

```css
.child {
  position: absolute;
  top: calc(50% - 50px);    /* 减去自身高度的一半 */
  left: calc(50% - 100px);
  width: 200px;
  height: 100px;
}
```

### 3. 面试官：不依赖尺寸的方案呢？

**回答**：五种，共同点是偏移或对齐由布局机制自己算，不读元素的宽高。

**绝对定位 + `transform`**：`translate` 百分比参照自身尺寸，无需知道宽高。注意 `transform` 创建层叠上下文，半像素偏移模糊。

```css
.parent { position: relative; }

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

**Flexbox**：弹性布局分配空间；`margin: auto` 吸收自由空间，块级流垂直 auto margin 为 0。

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

**Grid**：`place-items` 是 `align-items` 与 `justify-items` 的合写；`place-self: center` 或 `margin: auto` 均可。

```css
.parent {
  display: grid;
  place-items: center;
}
```

**`display: table-cell`**：垂直靠 `vertical-align`，水平靠 `text-align` + `inline-block`，无需定尺寸；代价是 `margin` 失效。

```css
.parent {
  display: table-cell;
  vertical-align: middle;
  text-align: center;
  width: 300px;
  height: 200px;
}

.child { display: inline-block; }
```

**块级 `align-content`**：块级容器也可用 `align-content: center`，无需额外 `display`。

```css
.parent {
  height: 300px;
  align-content: center;
}
```

### 4. 面试官：这些方案常见的失败点有哪些？

**回答**：七个高频失败点：

1. **高度塌陷**：子元素脱离文档流，父元素无内容时高度为 0。
2. **定位上下文缺失**：父元素 `static` 时参照更远的已定位祖先或初始包含块。
3. **`inset:0 + margin:auto` 在 `width:auto` 时拉伸填满**。
4. **`transform` 半像素模糊**：设偶数尺寸或用 Flex/Grid。
5. **`line-height` 继承**：多行文本需重置。
6. **块级垂直 `margin: auto` 无效**：需 `display: flex/grid`。
7. **`table-cell` 改变布局**：`margin` 失效。

### 5. 面试官：能总结一下吗？

**回答**：一张表收尾——定尺寸方案的价值是兼容老浏览器，不定尺寸的现代方案首选 Flex 和 Grid：

| 方案 | 需要定宽高 | 是否脱离文档流 | 浏览器支持 | 适用场景 |
| --- | --- | --- | --- | --- |
| 绝对定位 + 负 margin | ✅ | ✅ | 全部 | 老项目、尺寸固定 |
| 绝对定位 + `inset:0` + `margin:auto` | ✅（普通元素） | ✅ | 全部 | 尺寸固定的弹窗/图标 |
| 绝对定位 + `transform` | ❌ | ✅ | IE9+ | 不定尺寸的浮层、加载动画 |
| `line-height` | 单行文本 | ❌ | 全部 | 单行文字按钮 |
| Flexbox | ❌ | ❌ | IE10+（部分属性有前缀） | 现代布局首选 |
| Flex/Grid + `margin: auto` | ❌ | ❌ | IE11+（Grid 需新版本） | 单个子元素居中 |
| Grid + `place-items` | ❌ | ❌ | 主流现代浏览器 | 现代布局首选 |
| `table-cell` | ❌ | ❌ | 全部 | 兼容性要求极高的老项目 |
| 块级 `align-content` | ❌ | ❌ | 2024 年后新版本 | 简单块级垂直居中 |
