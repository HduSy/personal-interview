# 01. src 与 href 的区别

## 核心区别

* **`src`（Source，源）**：**将外部资源下载下来，应用到当前文档**。
  * **图片（`<img>`）**：浏览器会下载图片，然后替换掉 `<img>` 标签的内容。
  * **脚本（`<script>`）**：浏览器会下载、解析并执行代码，应用到当前文档。
* **`href`（Hypertext Reference，超文本引用）**：**在当前文档与外部资源之间“建立关联”**。
  * 例如引入样式表（`<link rel="stylesheet">`）或跳转链接（`<a>`），只负责确立联系，不会替换标签自身。

---

## 阻塞机制说明

> **澄清误区**：“图片和框架等元素在处理时也会暂停其他资源的下载和处理”是**错误**的。

* 除了未加 `async` / `defer` 的同步 `<script>` 脚本会阻塞 HTML 解析之外，**图片（`<img>`）和框架（`<iframe>`）在处理时是完全异步加载的，不会阻止其他资源的下载和处理**。
