# 01. src 与 href 的区别

## 高频问答

### 1. 面试官：src 和 href 有什么区别？

**回答**：核心区别是**对文档的作用方式不同**——`src` 是**将外部资源下载下来，应用到当前文档**；`href` 是**在当前文档与外部资源之间建立关联**，不会替换标签自身的内容。

- **`src`（Source，源）**：浏览器会下载资源并让它作用于当前文档。图片（`<img>`）：下载图片，然后替换掉 `<img>` 标签的内容；脚本（`<script>`）：下载、解析并执行代码，应用到当前文档。
- **`href`（Hypertext Reference，超文本引用）**：只负责确立联系。引入外部样式表（`<link rel="stylesheet">`）或跳转链接（`<a>`）用的都是它。

### 2. 面试官：哪些标签用 src，哪些用 href？

**回答**：**内容会被资源替换或执行的标签用 `src`**：`<img>` 下载图片、替换标签内容，`<script>` 下载并执行代码。**只需要指向一个地址、建立引用关系的标签用 `href`**：`<link rel="stylesheet">` 关联外部样式表，`<a>` 声明跳转目标，都不替换标签自身的内容。
