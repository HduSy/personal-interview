# 01. src 与 href 的区别

## 高频问答

### 核心区别

* **`src`（Source，源）**：**将外部资源下载下来，应用到当前文档**。
  * **图片（`<img>`）**：浏览器会下载图片，然后替换掉 `<img>` 标签的内容。
  * **脚本（`<script>`）**：浏览器会下载、解析并执行代码，应用到当前文档。
* **`href`（Hypertext Reference，超文本引用）**：**在当前文档与外部资源之间“建立关联”**。
  * 例如引入外部样式表（`<link rel="stylesheet">`）或跳转链接（`<a>`），只负责确立联系，不会替换标签自身的内容。
