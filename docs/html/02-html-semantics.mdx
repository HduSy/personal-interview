# 02. 对 HTML 语义化的理解

## 1. 什么是 HTML 语义化？

根据内容的结构和含义，选择最恰当的 HTML 标签，而不是通篇使用无意义的 `<div>` 和 `<span>`（即“见名知意”）。

---

## 2. 为什么要做语义化？（三大核心价值）

1. **可读性与可维护性（对开发者）**：  
   代码结构清晰，利于团队协作和后期维护；在没有 CSS 加载的情况下，页面也能保持良好的内容层次。
2. **SEO 友好（对搜索引擎）**：  
   搜索引擎爬虫依赖标签来理解页面内容的权重和上下文（如 `<h1>`、`<main>`、`<article>`），有利于搜索引擎抓取与排名。
3. **无障碍访问（对屏幕阅读器 a11y）**：  
   屏幕阅读器等辅助设备能根据标签语义（如 `<nav>`、`<header>`、`<button>`）准确向视障人士传达网页结构与交互意图。

---

## 3. 常见语义化标签

* **页面结构**：`<header>`（页眉）、`<nav>`（导航）、`<main>`（主体）、`<article>`（独立文章）、`<section>`（章节）、`<aside>`（侧边栏）、`<footer>`（页脚）。
* **文本与交互**：
  * 用 `<button>` 替代 `<div onclick>`（具备键盘聚焦与默认交互）；
  * 用 `<strong>` / `<em>` 表达语气强调（而非单纯视觉加粗倾斜）；
  * 表单中使用 `<label for="...">` 提升可用性与无障碍支持。
