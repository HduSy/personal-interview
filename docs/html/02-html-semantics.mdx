# 02. 解释 HTML 语义化

## 1. 什么是 HTML 语义化？

HTML 语义化（Semantic HTML）是指根据内容的结构和含义，选择最恰当的 HTML 标签来标记页面元素（例如用 `<header>` 表示页眉、`<article>` 表示独立文章、`<nav>` 表示导航），而不是通篇使用无意义的 `<div>` 和 `<span>` 来堆砌页面。

简而言之，语义化的核心原则是：**用正确的标签做正确的事，让标签本身就能「自解释」其包裹的内容。

## 2. 为什么要实现 HTML 语义化？（核心优势）

### 提升无障碍访问性（Accessibility / a11y）

屏幕阅读器等辅助技术高度依赖语义化标签来解析页面结构。例如，遇到 `<nav>` 时读屏软件会告知视障用户这里是导航区，遇到 `<button>` 会提示可点击，而纯 `<div>` 则无法提供这些上下文导航信息。

### 有利于搜索引擎优化（SEO）

搜索引擎爬虫通过 HTML 标签来理解页面内容的权重和层级。`<h1>` 中的关键词权重远高于普通 `<div>`；`<article>` 和 `<main>` 能帮助爬虫快速定位页面的核心正文，从而提升搜索排名。

### 提高代码可读性与可维护性

语义化代码自带清晰的文档结构，降低了团队协作的沟通成本。在没有 CSS 样式的情况下，语义化良好的页面依然能呈现出清晰的逻辑层级（即「裸奔」状态下依然可读）。

### 便于多设备解析与内容提取

浏览器的「阅读模式」、智能手表、RSS 订阅器以及大模型网页解析器，都会直接抓取 `<main>`、`<article>`、`<time>` 等标签来提取正文和元数据，过滤掉 `<aside>` 或 `<footer>` 中的非核心内容。

## 3. 常见语义化标签与非语义化对比

| 页面区域 / 内容 | 非语义化写法（避免） | 语义化写法（推荐） | 核心语义说明 |
| --- | --- | --- | --- |
| 页面主结构 | `<div class="header">` | `<header>` | 页面或章节的头部区域（通常包含 Logo、主标题） |
| 导航栏 | `<div class="nav">` | `<nav>` | 主导航链接区域 |
| 核心主内容 | `<div class="main">` | `<main>` | 页面独有的核心主体内容（每个页面仅限一个） |
| 独立内容块 | `<div class="post">` | `<article>` | 可独立分配、复用的完整内容（如博客文章、新闻、评论） |
| 主题分节 | `<div class="section">` | `<section>` | 文档中的主题分组，通常包含一个标题（`<h2>` 等） |
| 侧边栏 / 附加信息 | `<div class="sidebar">` | `<aside>` | 与主内容间接相关的附属信息（如侧边栏、广告、相关链接） |
| 文本强调 | `<b>` / `<i>` | `<strong>` / `<em>` | `<strong>` 表重要性加重，`<em>` 表语气强调（非单纯视觉粗体 / 斜体） |
| 图片与图注 | `<div><img><p>...</p></div>` | `<figure>` + `<figcaption>` | 独立的流内容（图表、照片、代码块）及其说明文字 |

## 你的回答

HTML 的标签语义化，是指根据页面的内容和含义来选择正确的 HTML 标签，而不是只用 div 和 span 去堆砌。

做好 HTML 语义化能够带来以下好处：
1. 有利于 SEO 优化：搜索引擎爬虫可以根据标签所代表的语义，更好地理解页面的权重和层级。比如说 H1 就代表页面的标题，它的权重远比 div 大。
2. 有助于无障碍友好：像屏幕阅读器或者是键盘，可通过 Tab 或者 Enter 键与页面进行交互。
3. 代码可读性很高：即便页面失去 CSS 样式，也有清晰的层级结构

常见的语义化标签有：main、aside、section、article 等等。
