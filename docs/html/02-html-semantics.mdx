# 02. 对 HTML 语义化的理解

## 1. 什么是 HTML 语义化？

根据内容的结构与含义选择正确的标签，做到“见名知意”，而不是通篇使用无语义的 `<div>` 和 `<span>`。

---

## 2. 核心作用与优势

1. **有利于搜索引擎优化（SEO）**：使搜索引擎爬虫能够更好地识别和理解页面的结构与内容含义，利于抓取和排名。
2. **结构清晰（无样式也能清晰表达）**：即便页面失去 CSS 样式，原有的内容与骨架结构也能清晰表达。
3. **利于团队协作与无障碍访问**：提升代码可读性，且便于屏幕阅读器等辅助设备准确解析。

---

## 3. 常见语义化标签

* `<header>`：页眉 / 头部
* `<main>`：页面主体核心内容
* `<aside>`：侧边栏 / 附属内容
* `<footer>`：页脚 / 底部
* `<section>`：文档中的独立章节或区块
