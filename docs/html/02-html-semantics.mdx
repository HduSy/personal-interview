# 02. 对 HTML 语义化的理解

## 1. 什么是 HTML 语义化？

根据内容的结构与含义选择正确的标签，做到“见名知意”，而不是通篇使用无语义的 `<div>` 和 `<span>`。

---

## 2. 核心作用与优势

1. **有利于搜索引擎优化（SEO）**：爬虫能够根据标签的语义更好地理解内容与页面结构。
2. **结构清晰**：即便页面失去 CSS 样式，原有的骨架结构也能清晰表达。
3. **无障碍友好**：便于盲人屏幕阅读器等辅助设备识别页面结构并进行无障碍导航。

---

## 3. 常见语义化标签

* `<header>`：页眉 / 头部
* `<nav>`：导航
* `<main>`：页面主体核心内容
* `<aside>`：侧边栏 / 附属内容
* `<footer>`：页脚 / 底部
* `<section>`：文档中的独立章节或区块
