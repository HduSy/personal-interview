# 08. 行内元素、块级元素与空（void）元素有哪些？

## 1. 元素的核心分类与表现本质

在 HTML 和 CSS 规范中，元素根据默认的渲染盒模型与排版流行为，主要分为**块级元素**与**行内元素**；而从 HTML 语法闭合结构来看，还存在一类特殊的**空（void）元素**。

它们的核心差异主要体现在：**是否独占一行、宽高与内外边距的计算规则、以及标签是否可以包裹子节点**。

## 2. 三大类型详解与常见标签清单

### (1) 块级元素（Block-level Elements）

默认样式为 `display: block`（或 `table`、`list-item` 等）：

- **常见标签**：
  - 结构容器：`<div>`、`<section>`、`<article>`、`<aside>`、`<header>`、`<footer>`、`<nav>`、`<main>`
  - 文本与排版：`<p>`、`<h1>`~`<h6>`、`<blockquote>`、`<pre>`、`<hr>`
  - 列表与表格：`<ul>`、`<ol>`、`<li>`、`<dl>`、`<dt>`、`<dd>`、`<table>`
  - 表单容器：`<form>`
- **盒模型与排版特性**：
  1. **独占一行**：每个块级元素都会从新行开始，其后的元素也会被挤到下一行；
  2. **默认宽度**：在未显式设置宽度时，默认占满父容器的 100% 宽度；
  3. **尺寸与边距完全生效**：可以自由设置 `width`、`height`、`line-height`，水平和垂直方向的 `margin`、`padding` 均完全生效；
  4. **嵌套规则**：块级元素内部通常可以容纳行内元素和其他块级元素（**注意特例**：`<p>` 标签内部严禁嵌套任何块级元素，否则会被浏览器强制拆断成多个 `<p>`）。

### (2) 行内元素（Inline Elements）

默认样式为 `display: inline`：

- **常见标签**：
  - 文本修饰：`<span>`、`<a>`、`<strong>`、`<b>`、`<em>`、`<i>`、`<mark>`、`<code>`
  - 表单文本辅助：`<label>`
- **盒模型与排版特性**：
  1. **不独占一行**：与其他行内元素在同一行水平排列，直到一行排满才自动折行；
  2. **尺寸由内容撑开**：直接设置 `width` 和 `height` **无效**；
  3. **边距生效受限（高频考点）**：
     - 水平方向的 `margin-left/right` 和 `padding-left/right` 正常生效；
     - 垂直方向的 `margin-top/bottom` **完全失效**；
     - 垂直方向的 `padding-top/bottom` 会渲染出背景色，但**不占用文档流空间**（不会推开上下相邻元素，会产生视觉覆盖）；
  4. **嵌套规则**：行内元素内部只能容纳文本或其他行内元素，**不能嵌套块级元素**（`<a>` 标签在 HTML5 中被特殊允许嵌套块级元素）。

> **💡 延伸考点：行内块元素（Inline-block / 置换元素）**
> 
> 像 `<img>`、`<input>`、`<button>`、`<textarea>`、`<select>` 等元素，在视觉上像行内元素一样并排排列，但又具备块级元素设置 `width`、`height`、`padding`、`margin` 的能力。在 CSS 规范中，它们属于 **置换元素（Replaced Elements）**，其视觉表现类似于 `display: inline-block`。

### (3) 空元素（Void / Empty Elements）

在 HTML 语法中，**没有闭合结束标签、不能包裹任何文本内容或子节点**的元素被称为**空元素（Void Elements）**。

- **全部常见空元素清单**：
  - `<img>`（图片）
  - `<input>`（输入框）
  - `<br>`（换行）
  - `<hr>`（水平分割线）
  - `<meta>`（文档元信息）
  - `<link>`（外部资源关联）
  - `<source>`（媒体源文件）
  - `<wbr>`（安全换行点）
  - `<col>`（表格列格式）
  - `<base>`（基准 URL）
  - `<area>`（图像映射热区）
- **语法规范**：
  - 在 **HTML5** 中，空元素末尾的自闭合斜杠是可选的（写 `<img>` 或 `<img />` 均完全合法）；
  - 在严谨的 **XHTML** 语法规范中，空元素必须以 `/>` 闭合。

## 3. 核心维度对比速查表

| 对比维度 | 块级元素（Block） | 行内元素（Inline） | 空元素（Void） |
| --- | --- | --- | --- |
| **独占一行** | 是 | 否（并排排列） | 视具体元素而定（如 `<hr>` 占整行，`<img>` 并排） |
| **可设宽高** | 是（自由指定 `width/height`） | **否（设置无效）** | 视是否为置换元素而定（`<img>/<input>` 可以，`<br>` 不行） |
| **垂直内外边距** | 完全生效 | `margin` 无效，`padding` 不占空间 | 置换型生效，非置换型无效 |
| **子节点嵌套** | 允许（`<p>` 除外） | 仅允许嵌套文本与行内元素 | **绝对不能包含任何子内容或闭合标签** |
| **代表标签** | `div`、`p`、`h1-h6`、`ul/li` | `span`、`a`、`strong`、`label` | `img`、`input`、`br`、`hr`、`meta`、`link` |

## 你的回答

HTML 里面的标签常分为三大类：块级标签、行内标签和空标签。

1. **块级标签**：
   - (a) 常见元素：div、p 标签，h1 到 h6，section、footer、header 等结构化元素，以及列表 ul、ol 和 form 元素。
   - (b) 特点：最大特点是独占一行。它的宽高、内外间距都是生效的，并且内部可以嵌套块级元素或行内元素。

2. **行内标签**：
   - (a) 常见元素：a 标签、span 标签，还有 strong 强调标签。
   - (b) 特点：内部不允许嵌套块级元素。它在水平方向上设置内外边距生效，垂直方向上设置外边距失效；设置 padding 不占用空间，但是会有背景色渲染。

3. **空标签**：
   - (a) 常见元素：link、meta、img（image）。
   - (b) 特点：它是自闭合的，没有闭合标签。内部不允许写任何其他元素或者文本。
